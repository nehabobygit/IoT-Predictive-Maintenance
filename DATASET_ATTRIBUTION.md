\## 4. Data Transparency



The project uses three external datasets and separately generated simulated sensor readings.



\- AI4I 2020 is a synthetic dataset.

\- SKAB and NAB are external benchmark datasets.

\- Simulated sensor readings are generated by the project's publisher.

\- Synthetic sensor fields are identified in the project's message metadata.

\- Dataset evaluation results are reported separately from live simulated readings.
